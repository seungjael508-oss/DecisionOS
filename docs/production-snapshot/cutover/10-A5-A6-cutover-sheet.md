## R5·R6 롤백 시 남는 데이터와 기존 코드의 해석

R5·R6은 함수 정의만 되돌리고 데이터는 지우지 않는다. 기존 코드(`dpl_Ysf2…`)는 처리 기록·연락 일정 테이블을 직접 읽지 않고 RPC로만 다루므로, 롤백 후 해석은 되돌린 함수 규칙이 정한다(A5·A6 SQL과 기존 코드 확인, 2026-10-19).

| A6 기간에 생긴 데이터 | R6 후 기존 규칙의 해석 | 영향 |
|---|---|---|
| 오늘 완료(COMPLETE) 기록 | 같은 날·같은 상태 지문이면 계속 숨긴다. '다음 관리일 도래' 사유가 붙어 있던 세대는 지문이 달라 **그날 다시 표시** | 일부 세대 당일 재노출(데이터 손상 없음) |
| 다음 관리일 미루기(SNOOZE, 지문 `R:…`) | 기존 규칙은 `R:` 지문과 맞추지 않으므로 **미루기가 무시되어 다시 표시** | 미루기 효과만 사라짐. 행은 남고, 유일 키 지문이 달라 기존 처리와 충돌 없음 |
| 방문 결과의 다음 방문일 | 기존 상담 저장 RPC의 '다음 접촉 일정'으로 저장된 것(기존 예정 일정 정리 포함)과 같은 형태 | 기존 화면에서도 다음 접촉일로 그대로 표시 |
